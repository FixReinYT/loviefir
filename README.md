# ЛовиЭфир
Многопользовательская видеоплатформа. Node.js 24, SQLite и файловое хранилище.
## Запуск
Выполните `node server.mjs` и откройте http://localhost:8080. Клиенты одного сервера видят общие каналы и видео. Пароли хешируются с индивидуальной солью, сессии хранятся на сервере.
## Размещение
`docker build -t loviefir .`
`docker run -d --name loviefir -p 127.0.0.1:8080:8080 -v loviefir-data:/app/data -e SECURE_COOKIE=1 loviefir`
Подключите HTTPS через обратный прокси с сохранением заголовка Host и лимитом тела запроса от 256 МБ. Для локального HTTP не задавайте SECURE_COOKIE. PORT и DATA_DIR настраиваются через переменные окружения.
## Возможности
Публикация MP4 и WebM до 256 МБ, прямые ссылки на просмотр, перемотка, поиск по названию и автору, подписки по времени публикации. Оценки «Больше/меньше по теме» суммируются для каждой темы отдельно для каждого зрителя. Исходные файлы воспроизводятся в поддерживаемых браузером кодеках. Транскодирование, модерация и квоты на канал пока не реализованы. Видео из предыдущего локального демо можно опубликовать из исходных файлов.
